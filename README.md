# Інструкція щодо використання репозиторію

1. Склонуйте репозиторій

```bash
git clone [repository-url]
cd goit-algo-hw-06
```

2. Перейдіть у директорію проєкту та активуйте віртуальне середовище

```bash
 python -m venv .venv
 # On Windows:
 .venv\Scripts\activate
 # On Unix/MacOS:
 source .venv/bin/activate
```

3. Встановіть необхідні залежності

```bash
# Install all dependencies (including development tools)
pip install -r requirements.txt
```

4. Запустіть головний файл main.py

```bash
# Install all dependencies (including development tools)
python -m main
```

5. Запустіть одну з наведених нижче команд:

```bash
b -- побудувати граф
i -- отримати аналіз графу
h -- показати доступні команди
q -- вийти з програми
```

# Графи

## Завдання 1

Побудовано граф міст та селищ Обухівського району Київської області за допомогою NetworkX. Вершини (nodes) відповідають містам та селищам, ребра (edges) — зв’язкам між ними.

### Візуалізація

Граф візуалізується за допомогою matplotlib.pyplot. Візуалізація запускається командою `b`.

### Аналіз графу

При виконанні команди `i` обчислюються та виводяться наступні параметри:

- Кількість вершин: загальна кількість міст та селищ у графі.
- Кількість ребер: загальна кількість доріг між вершинами.
- Зв’язність: чи є граф повністю зв’язаним (Так — так, Ні — ні).
- Щільність графу: показує, яка частка можливих доріг між містами/селищами реально існує.
- Середній ступінь вершин: середня кількість доріг, що ведуть до одного міста/селища.
- Середній коефіцієнт кластеризації: характеризує тенденцію міст/селищ утворювати щільно зв’язані групи.
- Середній коефіцієнт центральності: показує середню “важливість” або вплив вершин у графі на основі їхніх зв’язків.
