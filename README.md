# Інструкція щодо використання репозиторію

1. Склонуйте репозиторій

```bash
git clone [repository-url]
cd goit-algo-hw-06
```

2. Перейдіть у директорію проєкту та активуйте віртуальне середовище

```bash
 python -m venv .venv
 # On Windows:
 .venv\Scripts\activate
 # On Unix/MacOS:
 source .venv/bin/activate
```

3. Встановіть необхідні залежності

```bash
# Install all dependencies (including development tools)
pip install -r requirements.txt
```

4. Запустіть головний файл main.py

```bash
# Install all dependencies (including development tools)
python -m main
```

5. Запустіть одну з наведених нижче команд:

```bash
b -- побудувати граф
i -- отримати аналіз графу
с -- порівняти DFS та BFS алгоритми
h -- показати доступні команди
q -- вийти з програми
```

# Графи

## Завдання 1

Побудовано граф міст та селищ Обухівського району Київської області за допомогою NetworkX. Вершини (nodes) відповідають містам та селищам, ребра (edges) — зв’язкам між ними.

### Візуалізація

Граф візуалізується за допомогою matplotlib.pyplot. Візуалізація запускається командою `b`.

### Аналіз графу

При виконанні команди `i` обчислюються та виводяться наступні параметри:

- Кількість вершин: загальна кількість міст та селищ у графі.
- Кількість ребер: загальна кількість доріг між вершинами.
- Зв’язність: чи є граф повністю зв’язаним (Так — так, Ні — ні).
- Щільність графу: показує, яка частка можливих доріг між містами/селищами реально існує.
- Середній ступінь вершин: середня кількість доріг, що ведуть до одного міста/селища.
- Середній коефіцієнт кластеризації: характеризує тенденцію міст/селищ утворювати щільно зв’язані групи.
- Середній коефіцієнт центральності: показує середню “важливість” або вплив вершин у графі на основі їхніх зв’язків.

## Завдання 2

У цьому завданні використовується граф, створений у Завданні 1 (граф міст та селищ Обухівського району Київської області), для знаходження шляхів між вершинами за допомогою алгоритмів **DFS** (пошук у глибину) та **BFS** (пошук у ширину).

### Аналіз результатів

При виконанні команди `c` програма виводить послідовності відвіданих вершин для обох алгоритмів. Стартовою точкою є місто Обухів.

- **BFS (пошук у ширину)** виводить всі міста, які з'єднані дорогами з містом Обухів перед переходом до наступного міста. Тому послідовність відвідування відображає поширення "в ширину" - спочатку обробляються всі безпосередньо з’єднані з початковим містом населені пункти, потім їхні сусіди і так далі.
- **DFS (пошук у глибину)** йде якнайдалі вздовж одного шляху, перш ніж повернутися і дослідити інші шляхи. Через це міста відвідуються "по прямій" доки алгоритм не доходить до міста, від якого не йдуть дороги в нові міста і селища, після чого повертається назад по маршруту до останнього міста, яке ще має дорогу до невідвіданих населених пунктів. Отже, послідовність значно відрізняється від BFS.
